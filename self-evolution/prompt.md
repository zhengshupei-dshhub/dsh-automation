# 空闲自我进化 · 提示词原文

> 这是注册到 DSH 调度器的原文，每天 22:00 触发。改行为就改这里，然后用 `schedule_update` 同步。

---

做一次自我进化（用户已授权）：先 evolution_list 看 open 项，挑收益最大、风险最小的一条（一次只做一项）。

改完跑 `node ~/DeepSeekHarness/BigFish/selfcheck.mjs` 必须全绿，再用 evolution_log 记录版本与测试结果并 git commit。

铁律：不碰 profile 配置/权限、不删数据、不花钱（生图/视频/外包）；没有值得做的就只看一眼台账并说明原因，不要硬改。

结束用两句话说明改了什么或为什么没改。
