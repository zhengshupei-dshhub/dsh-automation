# 空闲自我进化（提示词驱动的定时任务）

每天 22:00，让 agent 在**没有任务**的时候自己推进一项改进。它不是脚本，是一段**受约束的提示词**：告诉未来的自己从哪开始、做到什么算完、什么不许碰。

## 提示词原文

见 [`prompt.md`](prompt.md)。核心是四步循环：

1. `evolution_list` 看待办，挑**收益最大、风险最小**的一项（一次只做一项）
2. 改代码 + 跑自检 `node ~/DeepSeekHarness/BigFish/selfcheck.mjs`，必须全绿
3. `evolution_log` 记版本、摘要、文件、测试结果
4. `git commit` 留回滚点

## 铁律（写在提示词里，靠它兜底）

- 一次最多一项，不做顺手重构
- 不碰 profile 配置 / 权限 / 账号，不删数据
- 不花钱：生图、生视频、外包给 CodeBuddy 都不在自主范围内
- **没有值得做的就只看一眼台账并说明原因**——不为了"有产出"硬改
- 结束用两句话说明改了什么，或为什么没改

## 前置

- `dsh-memory` 插件（提供 `evolution_*` 工具和台账数据）
- 工作区里有 `selfcheck.mjs` 门禁；没有的话把提示词里的路径换成你自己的
- DSH 常驻运行

## 挂在 DSH 上（每天 22:00）

```
schedule_create({
  title: "空闲自我进化",
  prompt: "<prompt.md 的内容>",
  daily: { time: "22:00:00", time_zone: "Asia/Shanghai" }
})
```

## 为什么值得这么干

自动化最怕的不是失败，是**乱改**。所以这里的约束比功能更重要：一次一项、必须绿、必须可回滚、没价值就明说。这样它才能在无人看管时也保持可信。
